# مُشرِفي — Mushrifi

تطبيق أندرويد لإدارة شؤون التلاميذ والسجلات المدرسية، مبني على واجهة عربية ويعمل محلياً على الهاتف.

## مكونات المشروع

- `index.html`: نسخة الويب وواجهة التطبيق.
- `android/`: مشروع Android الأصلي الذي يضم WebView والجسر البرمجي وقاعدة البيانات المحلية والتنبيهات.
- `android/app/src/main/assets/`: ملفات الواجهة والأصول والصور والتوقيع.
- `.github/workflows/build-apk.yml`: بناء APK وتجهيز حزمة المشروع الكاملة تلقائياً.
- `manifest.webmanifest` و`sw.js`: ملفات نسخة الويب القابلة للتثبيت.
- `icon-192.png` و`icon-512.png`: أيقونات التطبيق.

## الوظائف التي يتضمنها المشروع

- إدارة قائمة التلاميذ والبحث عنهم وفتح الملف الفردي.
- سجلات الغياب والتأخر والملاحظات والتبرير.
- المخالفات والتقارير والاستدعاءات.
- النسخ الاحتياطي والاستعادة بصيغة JSON.
- استيراد قوائم CSV.
- الأوامر الصوتية العربية، ومنها طلب فتح ملف تلميذ بالاسم.
- تذكير بموعد حضور الولي قبل الموعد بيوم، مع دعم إعادة جدولة التذكيرات بعد إعادة تشغيل الهاتف.
- صفحة التوقيع والأصول المرتبطة بها.
- حفظ بيانات نسخة Android في قاعدة SQLite محلية مع تشفير البيانات المخزنة.

## بناء APK

يتطلب JDK 17 وGradle 8.9 وAndroid Gradle Plugin المحدد في ملفات المشروع.

من مجلد المشروع:

```bash
gradle --no-daemon -p android assembleDebug
```

الناتج:

```
android/app/build/outputs/apk/debug/app-debug.apk
```

## بناء المشروع من GitHub

كل دفع لتغيير داخل `android/` أو ملف سير العمل يشغّل بناء APK. كما ينشئ سير العمل ملفاً مضغوطاً باسم `Mushrifi-Complete-Source.zip` يحتوي ملفات المشروع المصدرية اللازمة، ويستبعد ملفات البناء المؤقتة ومجلد Git.

من صفحة Actions افتح آخر تشغيل ناجح، ثم نزّل:
- `mushrifi-apk` لتثبيت التطبيق.
- `mushrifi-complete-source` للحصول على المشروع كاملاً.

## حماية البيانات

- احتفظ بنسخة JSON احتياطية قبل تحديث التطبيق أو استيراد نسخة أخرى.
- لا تحذف بيانات التطبيق ولا تستخدم خيار حذف القائمة أثناء اختبار الاستعادة.
- نجاح بناء APK لا يعني أن كل الوظائف اختُبرت على كل جهاز؛ يجب تجربة الاستيراد والميكروفون والتنبيهات على الهاتف المستهدف.
- ملفات APK الناتجة حالياً هي نسخ Debug موقعة بمفتاح الاختبار الذي يوفره نظام Android Gradle Plugin. يلزم إعداد مفتاح توقيع خاص لإصدار توزيع نهائي ثابت.
